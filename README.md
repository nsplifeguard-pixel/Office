# AI Digital Workspace (Thai)

เว็บต้นแบบห้องทำงานดิจิทัลภาษาไทย รองรับหน้าจอ iPad, iPhone และ Desktop

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Safari หรือเบราว์เซอร์สมัยใหม่
3. สร้างงาน โปรเจกต์ และเอกสารได้ทันที

## ความสามารถในรุ่นนี้
- Responsive UI ธีมดำ-แดง-เงิน
- Dashboard สรุปงานและเอกสาร
- CRUD งาน พร้อมสถานะ ความสำคัญ และวันครบกำหนด
- CRUD โปรเจกต์
- CRUD เอกสาร ค้นหา และคัดลอก
- ปฏิทินงานตามวันครบกำหนด
- ตั้งชื่อผู้ใช้/พื้นที่ทำงาน
- ส่งออกและนำเข้าข้อมูล JSON
- เก็บข้อมูลใน localStorage ของเบราว์เซอร์

## ข้อจำกัดที่ต้องทราบ
- รุ่นนี้เป็น frontend แบบไฟล์เดียวและเก็บข้อมูลในอุปกรณ์/เบราว์เซอร์นี้เท่านั้น
- ยังไม่มี Base44 Authentication, ฐานข้อมูลออนไลน์, การซิงก์ข้ามอุปกรณ์ หรือระบบสิทธิ์ผู้ใช้
- AI Assistant ยังไม่เชื่อมต่อ AI API และจะแจ้งให้ทราบแทนการแสดงคำตอบปลอม
- ก่อนใช้งานจริงหลายผู้ใช้ ให้เชื่อมต่อฐานข้อมูลและ Authentication ฝั่งเซิร์ฟเวอร์ พร้อมตั้งสิทธิ์การเข้าถึงข้อมูล
- อย่าใส่ API key ลับไว้ใน JavaScript ฝั่งหน้าเว็บ

## แนวทางต่อยอด Base44
นำ UI และแนวทางการทำงานไปใช้ในโปรเจกต์ Base44 แล้วเชื่อม entities กับ Base44 Database และ Base44 Authentication จากนั้นสร้าง backend function สำหรับเรียก AI provider โดยเก็บ API key ใน Secrets
